# 🛍️ Task 10: Market Segmentation using K-Means Clustering

📘 **Data Science Internship - EduTech Solutions**

---

### 🎯 Objective
To master unsupervised learning architectures and grouping patterns by analyzing mall consumer spending traits to map optimal market demographic clusters.

---

### 📈 Metrics & Strategy Summary

* **Optimal Grouping Selection:** Determined via Elbow Curve break analysis ($K=5$)
